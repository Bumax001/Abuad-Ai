# ABUAD Knowledge Base

Place official ABUAD PDF documents in this folder, then run:

`POST /api/knowledge/reindex`

with the `X-Admin-Key` header.

Recommended documents:
- Current admission guide
- Current school fee schedule
- Student handbook
- Academic calendar
- Programme/course catalogue
- Hostel regulations
- Examination regulations

Use current official documents only. Remove outdated versions to avoid conflicting answers.
